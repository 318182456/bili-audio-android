# 哔哩听单

原生 Android 应用，用于下载 B 站音轨和字幕、整理分集及后台收听。

## 打开项目

准备 Android SDK 35、JDK 17 和 Gradle 8.9。在 Android Studio 中打开本目录，Gradle 设置选择本机 Gradle 8.9，然后同步并在 Android 8.0（API 26）或以上的设备运行 `app`。

也可在工程目录运行 `gradle assembleDebug`。需要 Gradle Wrapper 时，运行 `gradle wrapper --gradle-version 8.9` 生成。

## 使用方法

1. 在「下载」页用搜索或收藏夹找视频，或粘贴 B 站链接、输入 BV 号。批量下载支持全选、从当前分 P 起选、选当前之后和仅选未下载，最多同时下载 3 个分 P 的音轨。
2. 选择「音频和 AI 字幕」。登录后可读取账号可见的站内字幕，也可将搜索结果收藏到自己的 B 站收藏夹。站内字幕缺失时，手机会下载一次约 240 MB 的 SenseVoice 模型，随后在本机生成字幕。
3. 下载完成后，在「播放」页的「已下载剧集」里展开书名，点选一集即可播放。自动分集不完整时，可在「管理」页点对应分 P 的「编辑切点」试听和修正。「导出分集」可生成单独的 M4A 和对应 SRT。
4. 播放页上滑字幕快进，下滑后退，松手跳转。底部可播放或暂停、切集和快进 30 秒。需要和别的音频应用一起播放时，开启「同时播放」。
5. 「管理」页按书名列出下载和本地文件。支持按任务状态筛选，也能批量暂停、重试、导出和删除。开启「听完自动清理」后，一个分 P 的所有集都听完才会清理其本地文件，继续保留作品、切点和收听记录。「账号」页显示当前外观，亮色和暗色随系统切换。

《重回小渔村》P1 的第 1–5 集切点已通过报幕复核，下载后自动分集。

数据结构、切点和验收场景见 [Android 设计](DESIGN.md)。
